# Das Spiel ansehen (Vorschau)

## So geht es heute – privat und kostenlos

Bei jeder Änderung (jedem Pull Request) baut GitHub automatisch eine Vorschau-Datei.

1. Auf github.com das Repository öffnen → oben **Actions**.
2. Den obersten Lauf anklicken (grüner Haken) → unten bei **Artifacts** auf **fussball-simulator-vorschau** tippen.
3. Es lädt eine ZIP-Datei herunter. Darin liegt `index.html`.
4. `index.html` öffnen – im Browser auf Laptop oder Handy. Es braucht keine Installation und kein Internet (ohne Internet sieht nur die Schrift etwas anders aus).

Auf dem iPhone: ZIP in der Dateien-App antippen (entpackt sich), dann `index.html` antippen → „Teilen“ → in Safari öffnen. Auf Android: mit einer Dateimanager-App entpacken und mit Chrome öffnen.

Die Datei bleibt 30 Tage abrufbar und ist nur für Personen sichtbar, die Zugriff auf das Repository haben.
